# Declarations

## Ethics approval and consent to participate

This study analysed only the publicly available, de-identified FedBCa dataset (Zenodo record 10409145, CC BY 4.0). The original investigators obtained ethics approval and handled informed consent [@fedbca]. No new data were collected, so no additional institutional review board approval was required.

## Consent for publication

Not applicable.

## Availability of data and materials

The FedBCa dataset is available from Zenodo (<https://doi.org/10.5281/zenodo.10409145>). The analysis code is released under the MIT licence: {{CODE_URL}}. The release includes the analysis plan written before model training, all split assignments, hyper-parameter grids, random seeds, the pinned software environment, the tumour-level predictions of every model and protocol, and the scripts that regenerate every figure and table.
